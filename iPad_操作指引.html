焊缝疲劳合规检查器 · iPad 操作指引

适用设备：iPad Pro 2025 11″ M5（带 LiDAR）· 系统 iPadOS 18+ · 日期 2026-09

路径 A：PWA（Safari 安装，零 Mac 依赖，今天可用） 路径 B：原生 LiDAR App（毫米级自动识别，需 Mac 构建）

A PWA 安装与使用（推荐先走这条）

把网页当 App 装到 iPad 主屏幕，照片识别 + 自动缺陷识别 + 报告导出全部在端侧完成。唯一限制：WebKit 沙箱下无法用 LiDAR，尺寸靠参照物（银行卡 85.6mm）标定。

① 部署（拿到链接，在电脑上做）

  1. 把整个 app_ios/pwa/ 文件夹拖到 Netlify Drop（app.netlify.com/drop），松手即得 https://xxx.netlify.app 链接。
  2. 备选：Cloudflare Pages / GitHub Pages / Tiiny.host，或直接用本地静态服务器。链接必须是 HTTPS。

② 在 iPad 上安装（只用 Safari）

  1. 打开 Safari（蓝色 compass 图标），地址栏输入上面的链接并打开。
  2. 等页面加载完（首次必须联网，让 Service Worker 缓存资源）。
  3. 点顶部地址栏右侧的 分享按钮（⬆ 方框箭头）→ 下滑找到 “添加到主屏幕”。
  4. 确认名称（默认“焊缝疲劳检查”），点右上角 添加。回到桌面即出现图标，点开全屏离线运行。
图：Safari 分享面板 → “添加到主屏幕”

③ 日常使用

  1. 点主屏图标打开（全屏、无地址栏）。
  2. 点 “拍摄 / 选择照片”：iOS 弹出“拍摄 / 从相册选择”面板，两种方式都能用。
  3. 选图后程序自动识别疑似缺陷（气孔 / 余高 / 咬边），写入清单，你复核微调。
  4. 填好接头类型、荷载方向、改善措施后，点 “导出报告(PDF)”：弹打印面板 → PDF → 存储到“文件”App。
⚠️ 安装只能用 Safari。Chrome/Edge 不会显示“添加到主屏幕”。首次需联网；之后断网可用。
✅ 装好后：拍照识别 + 自动缺陷识别 + 疲劳判定 + 报告导出，全部离线完成。

B 原生 LiDAR App 安装与自动识别

走 ARKit(LiDAR) 毫米级识别焊缝余高、左右焊趾咬边、错边。需 Mac + Xcode 16 构建一次，再分发到 iPad。

① 构建与分发（在 Mac 上做）

  1. Mac 打开 app_ios/native/WeldFatigueChecker.xcodeproj，目标选 iPad Pro（LiDAR）/ 真机，Xcode 16，iPadOS 18 部署目标。
  2. 编译（⌘R 真机跑；或 Archive 出 .ipa）。
  3. 分发：TestFlight（内测最简单）/ 企业签名 / Ad Hoc，装到同一台 iPad Pro 2025 M5。

② iPad 上自动识别焊缝（LiDAR）

  1. 打开 App → 底部切到 “外观检查” 页。
  2. 点 “📡 LiDAR 自动识别焊缝”（仅 LiDAR 设备显示此按钮）。
  3. 在弹出扫描页选 焊缝走向：自动 / 横向 / 纵向。屏幕中线即采样线（自动模式显示十字，横向→竖线，纵向→横线）。
  4. 将 iPad 正对焊缝，使采样线横切焊缝，保持 20–60cm，缓慢平移几秒建立深度。
  5. 点 “扫描焊缝”：LiDAR 读深度剖面，自动识别余高 / 咬边 / 错边并带实测 mm 写进缺陷清单。
  6. 回到外观检查页，逐条复核/微调；再走“设计审查 + 疲劳计算 → 报告”。
图：扫描页——黄色十字为采样线（自动模式），底部选焊缝走向
⚠️ 走向“自动”依赖深度图横/纵列变差比较；若焊缝很短或角度特殊，建议手动选“横向/纵向”更稳。
✅ 识别项自动写入缺陷清单（带实测 mm），无需参照物，精度显著优于 PWA 的视觉估计。
