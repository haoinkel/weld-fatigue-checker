焊缝缺陷数据集自增说明书

5 类缺陷 · 图文版 · 自行新增数据并重训 WeldFatigueChecker 模型

一、这是什么 / 适用场景

你在现场拍了更多焊道照片，想自己标好缺陷、加进训练集提升模型精度。本说明书配合 ml/weld_train.py 的多源合并架构，告诉你目录怎么放、框怎么标、脚本改哪两处、怎么重跑。

整体链路：整理 raw_mine/ → 脚本合并成 5 类 YOLO → --fresh 训 120 轮 → 自动导出 mlpackage

脚本对不在 5 类内的缺陷框会自动忽略，所以标错类别不会报错，只是被丢弃——放心按模板来。

二、5 类缺陷定义（标注时严格对照）

只标下面这 5 类。图里若有夹渣、飞溅等其他缺陷不要标。

id 0porosity气孔 焊接气孔
id 1crack裂纹 焊接裂纹
id 2undercut咬边 焊缝边缘凹陷
id 3overlap焊瘤/过高 多余焊缝金属
id 4unfused未熔合 未熔合/未焊透

四、标注格式（YOLO txt）

每个 .txt 一行一个框：<class_id> <cx> <cy> <w> <h>，全部归一化到 0~1。

标注框坐标示意

坐标换算（像素 → 归一化）

cx = (x_min + x_max) / 2 / img_width
cy = (y_min + y_max) / 2 / img_height
w  = (x_max - x_min) / img_width
h  = (y_max - y_min) / img_height

示例（1 个气孔 + 1 个咬边）

# weld_001.txt
0 0.512 0.430 0.120 0.090   # 气孔 porosity
2 0.300 0.880 0.200 0.040   # 咬边 undercut
标注工具：labelImg（存 YOLO txt 开箱即用）/ makesense.ai / Roboflow Annotate（国内需代理）。 也支持 VOC xml（labelImg 默认格式），脚本会自动解析 <name>porosity</name>，无需手动转。

五、接入训练脚本（改 2 处）

打开 ml/weld_train.py：

① 在 SOURCE_NAMES 字典加一行

SOURCE_NAMES = {
    ...
    'mine': ['porosity', 'crack', 'undercut', 'overlap', 'unfused'],
}

② 在 SOURCES 列表加一项

SOURCES = [
    ...
    {'root': 'raw_mine', 'key': 'mine', 'needs': None},   # 你的自建数据
]
REMAP 无需改：这 5 个英文名在脚本里已是 1:1 映射（如 'crack':'crack'）。 若 raw_mine/ 暂时不存在，脚本只打印"跳过"，不影响其他源训练。

六、运行流程（加数据后必须重建数据集）

→
改脚本 2 处SOURCE_NAMES / SOURCES
→
合并数据集统一 5 类 YOLO
→

→

# 新建 cell 运行
%run /home/aistudio/work/weld_train.py --fresh

看到 [合并] mine: 保留图-标对 N 即确认你的数据被读入；合并完打印 各类框数:{...} 可判断哪类偏少。

去掉 --fresh 则是"旧模型续吃新数据"；加量后建议用 --fresh 干净重训。 数据集切分确定性：md5(文件名)%5==0 进验证集（约 20%），可复现。

七、每类建议样本量

类别类型建议图数建议框数备注
porosity 气孔多数类≥150≥300基础量
overlap 焊瘤多数类≥150≥300基础量
unfused 未熔合多数类≥150≥300基础量
crack 裂纹少数类≥100≥200尽量多，脚本过采样×1.5补强
undercut 咬边少数类≥100≥200尽量多，copy_paste=0.45补强
路线 A 已含增强（copy_paste + 过采样 + mixup + 几何增广），但原始样本越多越稳。 验收线：porosity mAP50 ≥ 0.85；crack / undercut recall ≥ 0.9。

八、快速检查清单

  • raw_mine/classes.txt 5 行顺序正确
  • 每个有缺陷的图都有同名 .txt（或 .xml）
  • class_id 用 0~4，且只对应 5 类
  • 坐标已归一化到 0~1（无超界、无负数）
  • weld_train.py 已加 SOURCE_NAMES['mine'] 与 SOURCES 两项
  • 运行用 --fresh，并看到 [合并] mine: 保留图-标对 N
  • 核对 各类框数 后决定是否继续补某类
