拍照与标注实操指南

手机拍照要求 + 拍完如何标定 · 图文版 · 面向 WeldFatigueChecker 5 类焊缝缺陷数据集

一、总体原则（先记住这 4 句）

① 拍得清
缺陷要肉眼可辨，别靠后期"想象"。模糊、过曝、反光的照片模型学不到东西。
② 拍得正
手机尽量垂直焊面，斜着拍会让框变形、尺寸失真。
③ 拍得全
一张图里同类缺陷有多个就都标，别只标最明显的一个。
④ 拍得杂
不同工件、角度、光照都来点，模型才不容易"认死理"。

二、照片要求清单

项目要求为什么
分辨率≥ 1920×1080（建议 4K/1200 万像素以上）训练用 640，但高分辨率标注更准、细节更清
格式JPG / PNG；HEIC 需转 JPG脚本只认 jpg/jpeg/png/bmp
光线均匀柔光，无强反光、无浓重阴影金属反光会"洗掉"缺陷；阴影会伪造缺陷
角度垂直焊面 ±15° 内斜拍使框与尺寸失真
对焦焊道区域清晰，无运动模糊模糊图无法标注、模型也学不会
取景焊道占画面 40%~70%，缺陷清晰可见太远看不清、太近只剩局部无上下文
文件名英文/数字，如 weld_001.jpg，无空格中文避免跨系统编码乱码
数量每类 ≥100 张图（少数类 crack/undercut 越多越好）配合增强才稳；详见主说明书
重要提醒（可见光局限）：气孔、裂纹很多是皮下/内部的，普通手机照片看不见。 只拍表面可见的缺陷；不可见的别硬标（标了也是错的）。裂纹若太细，可用着色渗透探伤剂显影后再拍。

三、怎么拍（图文）

3.1 摆放与角度

斜拍会让缺陷框拉伸、尺寸失真 → 标注与训练都受影响

3.2 光线：柔和均匀 vs 强反光

高光"洗掉"缺陷，局部过曝丢失信息
缺陷清晰可辨，明暗过渡自然
手机拍照关掉闪光灯（金属一打就反光）。优先用：阴天自然光、靠窗柔光、或一块 LED 补光板（套柔光罩）。

3.4 每类缺陷：拍什么 / 怎么拍

id 0porosity气孔 拍焊道表面可见的孔洞群；近拍孔洞清晰
id 1crack裂纹 细裂纹用着色渗透剂显影后拍；沿焊缝/热影响区找
id 2undercut咬边 拍焊缝与母材交界的凹槽（焊趾处）
id 3overlap焊瘤/过高 拍焊缝上鼓起的多余金属
id 4unfused未熔合 表面未熔合缺口；内部不可见别硬标

3.5 常见错误（别踩）

✗ 别这样
• 开闪光灯打金属
• 手指/杂物入镜
• 一张图只拍半条焊道
• 只标最明显的那个缺陷
✓ 该这样
• 柔光无反光
• 画面干净只有焊件
• 完整焊道+热影响区
• 图内每个缺陷都标

四、拍完照片后怎么标定

4.1 把照片弄到电脑

手机 → 电脑：数据线 / 微信文件传输助手 / 网盘 / AirDrop（iPhone）。统一放进一个文件夹，按 weld_001.jpg 顺序改名（可用批量重命名工具）。

4.2 HEIC 转 JPG（iPhone 常见）

iPhone 默认 HEIC，需转 JPG：Windows 照片应用"另存为 JPG"，或用格式工厂 / 在线转换。脚本只认 jpg/jpeg/png/bmp。

4.3 选标注工具

工具类型适合说明
labelImg桌面软件首选，离线pip install labelimg，选 YOLO 格式直接出 txt
makesense.ai网页不想装软件免费、上传即标、导出 YOLO
Roboflow网页团队/自动化功能强，但国内需代理

4.4 labelImg 实操步骤

  1. 打开：运行 labelImg → Open Dir 选照片文件夹 → 先把格式切到 YOLO（左下角）
  2. 建类：Edit → Edit Labels，按序输入 porosity, crack, undercut, overlap, unfused（顺序=id 0~4）
  3. 画框：按 W 画矩形，紧贴缺陷边缘（别太松也别截断）
  4. 选类：在弹出的列表里点对应类别（或用快捷键 0~4）
  5. 保存：按 Ctrl+S，自动在同目录生成同名 .txt
  6. 下一张：按 D 切换，重复 3~5，直到所有图标完
标注界面示意：左图画框，右栏选类（快捷键 0~4）

4.5 标注要点

  • 框要贴边：刚好包住缺陷，不要留大空白也不要截断。
  • 不漏标：一张图里同一类有多个就分别画框，全部标出。
  • 一框一类：不要把两种缺陷框在一起；不同类型分开画。
  • 只标 5 类：夹渣、飞溅等不在这 5 类里的，不标（脚本也会自动忽略）。
  • 坐标范围：生成的 txt 里数字应在 0~1 之间；若出现负数或 >1 说明框超出图外，重画。

4.6 标完检查 + 接入训练

检查：每个 .txt 第一行形如 0 0.512 0.430 0.120 0.090，首位是 0~4。

接入：把 images/ + labels/ + classes.txt 按主说明书放进 raw_mine/，改脚本 2 处，--fresh 重训即可。（详见《数据集自增说明书_图文版》）

五、快速检查清单

  • 照片清晰、无模糊、无过曝反光
  • 手机垂直焊面 ±15° 内
  • 焊道占画面 40~70%，缺陷可见
  • 文件名英文数字、无空格中文
  • HEIC 已转 JPG（如适用）
  • 每类 ≥100 张（crack/undercut 越多越好）
  • 标注用 YOLO 格式，类序 0~4 正确
  • 每张图所有缺陷都已标，无漏标
  • txt 坐标均在 0~1 内
  • 已放入 raw_mine/ 并改脚本 2 处、--fresh 重训
