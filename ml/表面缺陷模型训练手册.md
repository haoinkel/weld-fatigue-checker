# 焊接缺陷表面模型训练手册（WeldDefectSurfaceModel，7 类）

> 适用范围：焊缝**表面可见光**缺陷检测模型（与 X 光/灰度域的 6 类模型 `WeldDefectModel` 是**两个独立模型**）。
> 本手册覆盖：数据准备 → 标注 → 训练（全量 / 续训）→ 导出 CoreML → 验证，面向「持续新增采集样本」的迭代场景。
> 配套脚本：`ml/build_surface_notebook.py`（生成器）、`ml/modelscope_train_surface.ipynb`（9 cell 训练 notebook）。

## 3. 标注是谁做的（重要澄清）

- **AI 不会自动给照片画框标注**。标注是「人用 labelImg / makesense.ai / Roboflow 之类把缺陷框画出来、导出 YOLO txt」。
- AI 的职责：写标注指南/模板、搭目录结构、写合并+训练+导出脚本、把你的标注喂进模型。
- 之前 `raw_mine` 的 40 张标注是**你按 `ml/数据集自增模板_5类缺陷.md` 标的**（非 AI 标）。
- **工作流**：拍照 → 标注工具画框 → 导出 `labels/<同名>.txt` → 重跑 notebook 自动并入。
- ⚠️ 光有 `images/` 图、没有同名 `labels/*.txt` → 该图在训练时被**跳过**，不参与。

## 4. 新增采集数据 = drop-in（零改代码）

### 4.1 目录结构

```
surfacedetecttrain/
└── collected/<批次名>/          ← 任意名，如 2026_11_batch1
    ├── images/                 ← *.jpg / *.png
    ├── labels/                 ← 与图同名的 YOLO txt（class_id cx cy w h，归一化 0~1）
    └── classes.txt             ← 每行一个类名（用 7 标准类或别名）
```

### 4.2 classes.txt 写法

每行一个类名，顺序即 idx（0~6）。直接用标准 7 类即可：

```
porosity
crack
overlap
spatters
good_weld
undercut
unfused
```

管道按「源类名 → 标准类」映射（与源类别顺序解耦），支持别名：
- `excess_reinforcement → overlap`
- `good_welding → good_weld`
- `spatter → spatters`
- 其他未知/非目标类（`bad_welding` / `defect` / `welding_line` / `slag inclusion` / `weld-defect-det`）自动**丢弃**。

### 4.3 已建好的占位

`surfacedetecttrain/collected/batch_001/` 已含 `images/`、`labels/` 和预填 7 类的 `classes.txt`。**直接往 `images/` 丢照片，标好后把 YOLO txt 放 `labels/` 即可**。

### 4.4 自动发现与去重

- 管道递归扫描 `surfacedetecttrain/` 下**所有**满足「`images/` + `labels/` + `classes.txt`」的根目录，自动并入。
- 按标注文件名集合**内容去重**，防嵌套解压残留（如 `Final_Dataset_YOLO_Test/Final_Dataset_YOLO_Test`）重复计入。
- 自动排除：`_merge_check`、`merged/`、`dataset/`、`runs/`。

### 4.5 YOLO 标注格式

`labels/<照片名>.txt` 每行：
```
<class_id> <cx> <cy> <w> <h>
```
- `class_id`：0~6（见 §1 表）
- `cx,cy,w,h`：归一化中心坐标与宽高（0~1）
- 例：`5 0.42 0.55 0.18 0.12` 表示咬边框

## 6. 训练模式：全量重训 vs 续训开关

### 6.1 默认 = 全量重训

每次重跑都从 `yolov8n.pt` 重新训练，数据 = 全部样本（旧+新）一起。已训旧样本会被再训，但底层通用特征来自预训练，不依赖旧权重。**最稳，不会遗忘少样本类**。

### 6.2 续训开关（cell 6 顶部）

```python
AUTO_RESUME = True      # 默认开：重跑时若工作区有上次缓存就自动续训
PREV_MODEL  = None      # 手动指定上一轮 best.pt 路径，优先级最高
```

决策顺序：
1. `PREV_MODEL` 设了且文件存在 → 用它的权重续训
2. 否则 `AUTO_RESUME and 存在 surfacedetecttrain/last_surface_best.pt` → 自动续训（cell 7 每次导出都会缓存该文件）
3. 否则 `yolov8n.pt` 从头

⚠️ 续训**仍喂全量数据**（仅初值更优、收敛更快），**不是**「只训新样本」。
⚠️ 纯增量训练有灾难性遗忘风险（40 张 finetune 曾塌方 mAP50=0.0036）。
⚠️ 若类别数/顺序变化（新增第 8 类），必须 `AUTO_RESUME=False` 从头，否则权重与类别对不上会报错。

### 6.3 攒批重训建议

别加几张就跑一轮 120 epochs。攒到几十~上百张（或按月）统一重训；`patience=30` 早停通常提前收敛，数据无大变化时不会跑满。

## 8. 快速操作卡（加一批新采集）

1. 新建 `surfacedetecttrain/collected/<批次>/`，放 `images/ labels/ classes.txt`。
2. 拍照 → 用 labelImg/makesense 标 → 导出 YOLO txt 进 `labels/`（class_id 用 0~6）。
3. 上传/保留到魔搭工作区（整目录或只传新 `collected/`）。
4. 重跑 `modelscope_train_surface.ipynb`：首次从头，之后自动从 `last_surface_best.pt` 续训。
5. 取出 `WeldDefectSurfaceModel.mlpackage` → 接 CI / 侧载验证。

## 9. 常见坑

- **只丢图、没标注** → 该图被跳过，不进训练。
- **嵌套解压多套目录** → 已去重，但仍建议解压别多套一层，免混淆。
- **改了类别又想续训** → 必崩，先 `AUTO_RESUME=False` 从头。
- **undercut / unfused 召回偏弱** → 框少属预期，后续现场补采增强。
- **误以为 AI 能自动标** → 标注必须人工（或训后模型预标 + 人校正），AI 只搭管道。
